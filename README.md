# Pawn's Journey

A chess-based adventure game built with Godot 4. RPG with chess puzzles and games for battles, focused on chess instruction where the player levels up alongside the character.

## Features
- Overworld exploration with RPG elements.
- Chess puzzles and matches integrated into the story.
- Correspondence chess system.
- Custom bot profiles and opening books.

## Development
This project is built using:
- **Godot 4.3**
- **C#** (for Chess Engine logic)
- **GDScript** (for Game logic and UI)

## How to Run
1. Clone the repository.
2. Open with Godot 4.3 or later.
3. Play!
