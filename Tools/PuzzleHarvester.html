Puzzle Harvester

Reads the Lichess puzzle database (CC0) and builds drill batches of beginner puzzles for Pawn's Journey: short, specific sets, easiest first. Everything runs in this page, on your computer; the file never leaves it and is read in small pieces, so the 1+ GB size is fine.

1. Choose the database file

...or drag lichess_db_puzzle.csv onto this box. (If you downloaded the .zst version, unzip it first.)

2. Choose the batches

Only ticked batches are searched for, so fewer batches scan faster.

3. Limits

Scanning keeps the best candidates for every batch in memory; nothing is written yet.

4. The batches

Each batch runs easiest to hardest. Click a batch name to preview its puzzles and drop individual ones.

Preview

Red square = first move from, green = to. Boards are drawn with White at the bottom.

5. Write the files

Choose your project's Data/PuzzlePacks folder (create it first if needed). One file per batch, e.g. 1a_mate_in_1_rook.json. Existing files with the same names are replaced.

Puzzle data: Lichess puzzle database, released under CC0 (public domain). Chess rules in this page: chess.js, BSD-2-Clause (notice included in the page source).
