Puzzle Harvester

Reads the Lichess puzzle database (CC0) and writes JSON puzzle packs for Pawn's Journey. Everything runs in this page, on your computer; the file never leaves it and is read in small pieces, so the 1+ GB size is fine.

1. Choose the database file

...or drag lichess_db_puzzle.csv onto this box. (If you downloaded the .zst version, unzip it first.)

2. Filters

Scanning only reads the file and keeps the best candidates in memory; nothing is written yet.

3. Pick the types of puzzle to write

Click a pack name to preview its puzzles and untick individual ones you don't like.

Preview

Red square = move from, green = move to. Boards are drawn with White at the bottom.

4. Write the files

Choose your project's Data/PuzzlePacks folder (create it first if needed). Existing files with the same names are replaced.

Puzzle data: Lichess puzzle database, released under CC0 (public domain). Chess rules in this page: chess.js, BSD-2-Clause (notice included in the page source).
