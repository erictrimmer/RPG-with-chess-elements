# Downtown Yorktowne — generated level

1960s fictional York, PA. 160 × 128 tiles (16 px), split into **20 chunks of 32 × 32 tiles**
(5 columns × 4 rows). Built from the LimeZu Modern Exteriors 16px sheets plus a few synthesized
pieces drawn in the same palette (curbs, track rails, pennants, big top, steeples, domes, lamps).

## Files

| File | What it is |
|---|---|
| `downtown_level.tscn` | The whole level: all 20 chunks instanced at their offsets, an empty y-sorted `Entities` node for NPCs, and `Markers` (spawn, doors, NPC spots, secrets). |
| `downtown_test.tscn` | Playable test: the level + `Entities/Player/player.tscn` at the depot spawn, camera clamped to the map. Press F6 on it. |
| `chunks/downtown_c<cx>_<cy>.tscn` | One scene per chunk. Chunk `(cx, cy)` covers tiles `x = cx*32 … cx*32+31`, `y = cy*32 … cy*32+31` and sits at pixel position `(cx*512, cy*512)`. Instance only the chunks you need, or stream them in and out. |
| `downtown_tileset.tres` | Shared TileSet: source 0 = terrain atlas, source 1 = objects atlas (each building or prop is stored as one contiguous block, so you can select it whole in the TileSet editor and paint it). |
| `downtown_terrain.png`, `downtown_objects.png` | The atlases. |
| `downtown.json` | The intermediate spec the scenes were built from (cells, collision rects, markers). |
| `level_test.gd` | Tiny script that clamps the camera to the level size. |

## Layers in every chunk (draw order)

| TileMapLayer | z_index | Contents | Collision |
|---|---|---|---|
| `Ground` | -4 | Grass, roads, sidewalks, plazas, dirt paths, water, creek walls, cliff faces | Water, flood walls, creek lips and cliff rims are solid. Grass, streets and sidewalks are not. |
| `Decals` | -3 | Road paint, crosswalks, rails, flat clutter | Never |
| `Objects` | -2 | Buildings and the lower part of props (trunks, lamp bases, booths) | Buildings fully solid, props at their base cells (trimmed to the drawn pixels) |
| `Overhead` | 5 | Tree canopies, lamp heads, steeples, tower tops, arches, pennants | Never; drawn **above** characters so they can walk behind them |

Put characters at z_index 0 (anywhere between `Objects` and `Overhead`); the `Entities` node is y-sorted for NPCs.

## Physics

All tile collision is on **physics layer 3 (bit value 4) — "World solids"**, as in the style bible §8.

> Note: `Entities/Player/player.tscn` currently uses the default `collision_mask = 1`, so outside the
> test scene the player will walk through anything on layer 3 (this was already true for
> `Market.tscn`). The test scene overrides the mask to `6` (NPC bodies + world). To fix it
> everywhere, set the player's `collision_mask` to 6 in `player.tscn`.

## Markers

`Markers/*` are `Marker2D` nodes with metadata `kind` = `spawn`, `door`, `npc`, `secret` (+ `id`, `role`, `building`). Use them to drop NPCs, doors/scene transitions (style bible trigger zones on layer 5) and hidden items.

## Regenerating / editing

The level is generated by `Tools/world_builder/build_downtown.py`:

```
python Tools/world_builder/build_downtown.py --godot
```

That rebuilds the atlases, TileSet and every scene in this folder (about 30 s; Godot runs headless).
**Hand edits to these scenes are overwritten by a rebuild**, so either make layout changes in the
district scripts (`Tools/world_builder/districts/*.py`), or stop regenerating and edit the scenes in
the editor from then on. The design brief is `Tools/world_builder/design/downtown_brief.md`.
